A program egy előre meghatározott vásznat képez le, ami a szobát alkotja, a szobán belül további, különböző méretű bútorokat hozhatunk létre amelyeket áthelyezhetünk a szobában az egér segítségével

Az indítás a main.py file futtatásával történik, nem szükséges telepíteni semmi egyebet

a sajat_modul_VB.py fileban találhatóak a bútor főosztály és ennek az al-osztályai, ezenfelül található még segédszámolási függvények, például az ütközésvizsgálatért felelős számolási függvény az utkozes_VB is itt található

a main.py tartalmazza a grafikai felület definiálását és itt történik a bútorok példányosítása is, a legkomplexebb része a kódnak itt található, ami a bútorok mozgatásáért felel, ez a leghosszabb elem, ugyanis sok váltázót kell figyelnie, annak érdekében,
hogy zökkenőmentesen fusson a program
